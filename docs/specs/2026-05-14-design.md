# Design Spec: Crochet Store MVP
Date: 2026-05-14

## Overview
- **Goal:** Retail online store for knitted products.
- **Tone:** Cozy, handmade, gentle.
- **Design System:** Cream, beige, light brown, pastel accents. Modern & clean layout. Responsive.

## MVP Features (Phase 1)
1. **Product Browsing:** Product listing with images, details, price, category filter (search/filter).
2. **Product Details:** High-quality image focus, description, add to cart.
3. **Cart Management:** Add, remove, update quantities.
4. **Checkout:** Secure ordering process, order history (basic).
5. **Admin Dashboard:** Manage products (CRUD), inventory tracking, order overview.

## User Roles
- **Guest:** Browse, search, filter.
- **Customer (Registered):** Checkout, order history, profile.
- **Admin:** Product/Inventory/Order management.
