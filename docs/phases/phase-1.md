# Phase 1: MVP (Storefront + Admin)

## Goals
- Functional e-commerce store with secure backend.
- Admin dashboard for inventory management.

## Layers
- **Layer 0:** Foundation (Next.js, Tailwind, Supabase setup).
- **Layer 1:** Storefront (Product listing, details, cart).
- **Layer 2:** Authentication & Checkout.
- **Layer 3:** Admin Dashboard (Product/Order mgmt).
