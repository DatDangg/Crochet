## Mô tả ý tưởng

App website bán len: nền tảng thương mại điện tử cho phép khách hàng xem/tìm kiếm/lọc sản phẩm len, thêm vào giỏ hàng, thanh toán, quản lý tài khoản và theo dõi đơn hàng. User chính gồm khách mua hàng, người dùng đã đăng ký và Admin/nhân viên quản lý kho. Tính năng chính: danh sách [BRIEF_CONTENT] chi tiết sản phẩm, tìm kiếm/lọc theo loại len/màu/giá/kích cỡ, giỏ hàng, mã giảm giá, checkout, tài khoản người dùng, wishlist, quản lý đơn hàng, đánh giá sản phẩm và dashboard Admin để quản lý sản phẩm, tồn kho, nhà cung cấp, báo cáo. Stack muốn dùng: Frontend Next.js, Backend Supabase gồm Auth, Database PostgreSQL, Storage cho ảnh sản phẩm, Row Level Security cho phân quyền User/Admin, Edge Functions nếu cần xử lý logic thanh toán hoặc webhook.
